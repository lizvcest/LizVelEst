# Portfolio

Proyecto final para poner en práctica los conocimientos adquiridos en las clases de desarrollo web: estructura con HTML, estilos con CSS y maquetación con Flexbox, junto con el control de versiones mediante Git y GitHub. A la vez, funciona como una breve presentación personal.

## Tecnologías
- HTML5
- CSS3 (maquetación con Flexbox)

## Herramientas
- Git (control de versiones)
- GitHub (alojamiento del repositorio)
